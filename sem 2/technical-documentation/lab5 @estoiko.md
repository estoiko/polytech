### 2.3.

Программа определяет, является ли введённое число простым.

Число называется простым, если оно больше 1 и делится только на 1 и на само себя.
Алгоритм перебирает делители от 2 до $\sqrt{n}$ включительно — если хотя бы один из них делит n нацело, число составное.
Проверка до  $\sqrt{n}$ достаточна: если у числа есть делитель, больший  $\sqrt{n}$, то соответствующий парный делитель будет меньше  $\sqrt{n}$ и уже был проверен.

```cpp
#include <iostream>
#include <cmath>

int main() {
    int n;
    std::cout << "Введите целое число: ";
    std::cin >> n;

    if (n < 2) {
        std::cout << n << " не является простым числом" << "\n";
        return 0;
    }

    bool is_prime = true;
    for (int i = 2; i <= static_cast<int>(std::sqrt(n)); ++i) {
        if (n % i == 0) {
            is_prime = false;
            break;
        }
    }

    if (is_prime)
        std::cout << n << " — простое число" << "\n";
    else
        std::cout << n << " — не является простым числом" << "\n";

    return 0;
}
```
